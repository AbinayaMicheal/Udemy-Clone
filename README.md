# Udemy Clone (Frontend Demo)

A simple Udemy-inspired frontend project built to demonstrate core web development skills using **HTML** and **basic CSS**.  
This project replicates the look and feel of an online learning platform, focusing on layout, styling, and responsive design.

---

##  Features
- Clean and structured homepage layout
- Course listing section with cards
- Navigation bar and footer
- Basic responsive design principles
- Purely frontend 

---

##  Tech Stack
- **HTML5**: For semantic structure
- **CSS3**: For styling and layout
